### Linux Learning Projects

## 📌 About

This repository documents my hands-on Linux command practice completed as part of a **Cloud & DevOps course**.

The objective of this project was to become familiar with the **Linux terminal and command-line environment** by working with directories, managing files, searching text, editing files, and performing common filesystem operations.

---

## 🛠️ Technologies

* **Kali Linux**
* **VMware Fusion**
* **Bash**
* **Linux CLI**

---

## 📚 Topics Covered

The following Linux concepts and commands were practiced:

* Linux File System
* Directory Navigation
* File Management
* Nano Editor
* `grep`
* `find`
* `wc`
* `head`
* `tail`
* Pipes `|`
* `sort`
* `uniq`
* `tr`

---

## 📂 Repository Structure

```text
Linux_search_project/
├── HR/
├── IT/
├── Sales/
└── Finance/
```

The project contains multiple department directories used to practice Linux file searching, text processing, and filesystem operations.

---

## 🎯 Learning Outcomes

After completing this practice, I can:

* Navigate the Linux filesystem
* Create and manage directories
* Create, edit, and delete files
* Search for files using `find`
* Search text using `grep`
* Count words and lines using `wc`
* Use pipes `|`
* Understand relative and absolute paths
* Work with the Nano text editor
* Perform basic Linux file and text-processing operations
